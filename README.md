## 🚀 Featured Projects

### 🐶 Petmily

> 반려동물 보호자와 펫시터를 연결하는 돌봄 구인·구직 플랫폼

Spring Boot 기반 REST API로 회원, 반려동물, 게시글, 댓글 기능을 구현했습니다.  
Spring Security와 JWT 기반 인증, HttpOnly Cookie, CSRF Token 검증, Kakao OAuth 2.0 로그인을 적용했습니다.

**주요 기술**

`Java 17` `Spring Boot` `Spring Security` `Spring Data JPA` `MySQL` `JWT` `OAuth2` `React`
